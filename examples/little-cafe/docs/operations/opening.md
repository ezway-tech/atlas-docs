## Before opening
- [ ] Switch on the espresso machine.
- [ ] Check the grinder and clean pitchers.
- [ ] Read the [menu](../menu/menu.md) for today’s prices.
- [ ] Count milk cartons and coffee bags using the [inventory guide](stock/inventory.md).
- [ ] Prepare one test drink with the [latte recipe](../menu/latte.md).

## Handover
- [ ] Write a comment on any instruction that needs an update.
- [ ] Confirm the ordering screen is ready.
- [ ] Open the door at 08:00.

## First order
Follow the [order flow](order-flow.md) from ticket to handover.
