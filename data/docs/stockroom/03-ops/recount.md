# Recount

Once a month, two people walk the aisle and count what is really there.

1. Print the list from the home screen.
2. Count each shelf. Do not trust the screen during the walk.
3. Enter the counted quantity. Stockroom writes one adjustment movement.
4. The [shelf map](../01-warehouse/shelves/shelf-map.md) stays the same. Only the quantity changes.

This folder is hidden in the sidebar so the dashboard can show how to bring it back.
